A design review agent that checks every screen before review

Design reviews spend too much time on the same mistakes: low contrast, off-grid spacing, wrong colours, small tap targets, unclear buttons. I built an agent that catches them in seconds, explains why each one matters, and fixes them, so reviews can focus on the real design decisions.

Started as a Figma plugin idea for our design quality checks. Rebuilt here so you can run it in the browser.

How it works

Agent architecture
Input

Read the frame

The plugin reads every layer in the selected Figma frame: position, size, colours, fonts and text.

Rules

Check the system

Deterministic checks for contrast, tokens, type scale, spacing, tap targets and the fold.

AI

Judge and explain

An LLM reviews copy and hierarchy, explains each issue in plain words and suggests the fix.

Output

Fix and report

One click applies token fixes. The report goes to the designer before the review, not after.

Rules handle what can be measured, so results are consistent. AI handles what needs judgement, like whether a button label is clear. In this browser version the AI suggestions are pre-written for the sample screens.

The rules come from the design system

What the agent checks

Colour tokens

Only system colours, and text must pass WCAG AA contrast (4.5:1, or 3:1 for large text).

Type scale

Six sizes only: 12, 14, 16, 20, 24 and 32. Anything in between is a sign of a one-off style.

Spacing and touch

Spacing on a 4 point grid, and every tap target at least 44 points tall.

Copy and hierarchy

Buttons say what happens next in a few words. One primary action per screen, visible without scrolling.

How I built it

Process

Listed review comments

Went through past design review notes and grouped the comments that kept repeating.

Turned them into rules

Each repeated comment became a rule tied to a design system token, with a clear pass and fail.

Split rules and AI

Measurable checks run as code. Judgement calls like copy and hierarchy go to the LLM.

Built it with Claude

Wrote the plugin and this browser version with Claude, testing each rule on real screens.

Designed the report

Every issue says what is wrong, why it matters and how to fix it, with one-click fixes where safe.

What it changes

Impact

Reviews focus on decisions. The basic checks are done before anyone looks at the screen.

Faster feedback. A designer gets a full check in seconds instead of waiting for the next review.

A stronger design system. Every fix points back to a token, so one-off styles stop spreading.
